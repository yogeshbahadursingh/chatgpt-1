## WordPress Requirements

- **Filename:** `screenshot.png`
- **Dimensions:** 1200x900 pixels (recommended)
- **Format:** PNG
- **Location:** Theme root directory (`people-planet-thrive/screenshot.png`)

## Impact

Without `screenshot.png`:
- Theme displays with a generic placeholder in WordPress admin
- Theme selection interface looks incomplete
- Professional presentation is compromised

With `screenshot.png`:
- Theme displays custom preview in admin
- Professional appearance maintained
- Users can see theme design before activation
