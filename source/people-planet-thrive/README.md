# People & Planet Thrive — WordPress Block Theme

**Theme Name:** People & Planet Thrive
**Theme URI:** https://ppthrive.com
**Version:** 2.3.3
**Requires WordPress:** 6.4+
**Requires PHP:** 8.0+

## Description

A sophisticated WordPress block theme for People & Planet Thrive — a global platform for research, scholarly publishing, education, and community collaboration.

Built with Full Site Editing, accessibility-first design, and editorial precision.

## Features

- Full Site Editing (FSE) with theme.json configuration
- Custom block patterns for scholarly and editorial layouts
- WooCommerce-compatible templates
- WCAG 2.2 AA accessibility
- Responsive design (320px — 1920px+)
- Schema.org structured data
- Custom block styles
- Editor enhancements
- Translation-ready

## Installation

1. Download the theme ZIP file.
2. In WordPress admin, go to **Appearance → Themes → Add New → Upload Theme**.
3. Select the ZIP file and click **Install Now**.
4. Activate the theme.

## Requirements

- WordPress 6.4 or higher
- PHP 8.0 or higher
- Companion plugin: **PPT Core** (recommended)

## Companion Plugin

This theme is designed to work with the **PPT Core** plugin, which provides:
- Custom post types (Journals, Articles, Researchers, etc.)
- Taxonomies
- Meta fields for scholarly data
- REST API extensions

## Customization

All visual customization is managed through:
- **Appearance → Editor** (Full Site Editing)
- **Appearance → Styles** (Global Styles)
- **Customizer** (for legacy options)

### Design Tokens

The theme provides the following design tokens via theme.json:

**Colours:**
- Deep Forest (#062E2B)

- Emerald (#126B52)
- Botanical Green (#4F8A52)
- Heritage Gold (#C69A45) — use sparingly
- Soft Gold (#E2BF73)
- Warm Ivory (#F8F5EE)
- Paper White (#FFFFFF)
- Ink (#101820)

**Typography:**
- Headings: Source Serif 4
- Body: System Sans
- Code: System Monospace
